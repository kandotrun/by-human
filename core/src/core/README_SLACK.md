# パーソナルAI Slackボット

パーソナルAIをSlackボットとして使用するための実装です。
ユーザーごとに独自のメモリを持ち、すべての機能をSlack上で利用できます。

## セットアップ方法

### 1. Slack Appの作成

1. [Slack API](https://api.slack.com/apps) にアクセスし、新しいアプリを作成します
2. 「From scratch」を選択し、アプリ名とワークスペースを設定します
3. 「Socket Mode」を有効にし、App Tokenを生成します（`xapp-`で始まるトークン）
4. 「OAuth & Permissions」でスコープを設定します:
   - `app_mentions:read`
   - `chat:write`
   - `im:history`
   - `im:read`
   - `im:write`
   - `files:read`
   - `files:write`
   - `canvases:read`
   - `canvases:write`
5. ボットトークン（`xoxb-`で始まるトークン）をコピーします
6. イベントサブスクリプションで以下を追加します:
   - `app_mention`
   - `message.im`
   - `canvas_mention`
7. アプリをワークスペースにインストールします

### 2. 環境変数の設定

1. `.env.example` をコピーして `.env` を作成します
2. 環境変数を設定します:
   ```
   SLACK_BOT_TOKEN=xoxb-your-bot-token
   SLACK_APP_TOKEN=xapp-your-app-token
   OLLAMA_MODEL=llama3.3
   ```

### 3. ボットの起動

```bash
# ディレクトリに移動
cd core/src

# ボットを起動
python -m core.slack_bot
```

## 使い方

### 基本的な会話

- DMでボットにメッセージを送信するか、チャンネルでボットをメンションします
- 通常の会話として質問や命令を送信できます

### コマンド

すべてのコマンドは `/` または `!` から始まります：

- `!help` または `/help` - ヘルプを表示
- `/remember <キー> <値>` - 情報を記憶
- `/forget <キー>` - 記憶した情報を忘れる
- `/profile` - 記憶している情報を表示
- `/settings` - 設定を表示
- `/search <クエリ>` - 関連する記憶を検索
- その他、CLIで利用可能なすべてのコマンドが使用できます

### Canvas共同編集メモ帳

Slackのキャンバス機能を使って、ユーザーとAIが共同で編集できるメモ帳が利用できます：

- `/memo <タイトル>` - 指定したタイトルのメモ帳を作成します
- `/memo list` - 現在のチャンネルで利用可能なメモ帳の一覧を表示します
- `/memo update <ID> <内容>` - 既存のメモ帳に内容を追加します（内容省略時はAIが自動で補足）
- `/memo history <ID>` - メモ帳の編集履歴を表示します

メモ帳内で「AIへの指示」セクションに指示を入力することで、AIからの回答を直接メモ帳に追加できます。

### 自動記憶

ボットは会話から重要な情報を検出し、記憶するかどうか確認します：

```
ユーザー: 私の好きな色は青です

ボット: なるほど、青が好きなんですね。私も青は落ち着く色で好きです。

確認: 「好きな色: 青」を記憶しておきますか？(y/n)
```

「y」または「はい」と答えると情報が記憶されます。

## トラブルシューティング

- **ボットが応答しない**: Slackトークンが正しいか確認してください
- **インポートエラー**: 必要なパッケージがインストールされているか確認してください
- **Ollamaエラー**: Ollamaサーバーが起動しているか確認してください
- **Canvas機能のエラー**: Slackアプリの権限スコープに `canvases:read` と `canvases:write` が含まれているか確認してください

## 注意事項

- 各ユーザーの会話や設定は個別に保存されます
- ボットを再起動すると、メモリ内の情報は失われますが、ファイルに保存された情報は保持されます
